          endpoint (/mcp/demo) — no account, no email. The principal is scoped
          to the demo workspace only, carries read-only reach (searchAtlas +
          executeSQL), and is rate-limited per client IP and per minted
          identity. Email capture is optional and only possible after the first
          answer (see POST /anonymous/email). Fails closed with a request id
          when the demo workspace cannot be resolved.
